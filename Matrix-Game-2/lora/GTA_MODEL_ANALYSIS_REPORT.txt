8. IMPLEMENTATION CODE SAMPLES
================================================================================

  A. Using PEFT Library (Recommended):

```python
from peft import LoraConfig, get_peft_model
from wan.modules.causal_model import CausalWanModel

# Load base model
model = CausalWanModel.from_pretrained('models/gta_distilled_model')

# Configure LoRA
lora_config = LoraConfig(
    r=16,  # rank
    lora_alpha=32,  # scaling factor
    target_modules=[
        'self_attn.q', 'self_attn.k', 'self_attn.v', 'self_attn.o',
        'cross_attn.q', 'cross_attn.k', 'cross_attn.v', 'cross_attn.o',
        'ffn.0', 'ffn.2',
    ],
    lora_dropout=0.05,
    bias='none',
    task_type='CAUSAL_LM'
)

# Apply LoRA
model = get_peft_model(model, lora_config)
model.print_trainable_parameters()
```

  B. Action-Focused LoRA (for control fine-tuning):

```python
lora_config = LoraConfig(
```

9. KEY ARCHITECTURAL FEATURES
================================================================================

  Diffusion Framework:
    • Type: Flow Matching / Rectified Flow
    • Objective: Velocity prediction (v = noise - x0)
    • Timestep Embedding: Sinusoidal (256-dim)
    • Denoising Steps: Typically 6-8 for distilled model

  Position Encoding:
    • Method: Rotary Position Embedding (RoPE)
    • Dimensions: Separate for time, height, width
    • RoPE Theta: 10000 (standard), 256 (action module)

  Normalization:
    • Layer Norm: For most layers
    • RMS Norm: For attention Q/K normalization
    • AdaLN: Adaptive layer norm with timestep conditioning

  Causal Architecture:
    • KV Caching: Enabled for efficient long video generation
    • Block Size: 3 frames per inference block
    • Window Size: 3 frames for action context
    • Local Attention: For temporal efficiency

10. TRAINING CONSIDERATIONS FOR LoRA
================================================================================

  Memory Requirements:
    • Full Model: ~24GB VRAM (bfloat16)
    • With LoRA (r=16): ~20-22GB VRAM
    • With LoRA (r=8): ~18-20GB VRAM
    • Gradient Checkpointing: Can reduce by 30-40%

  Training Speed (estimated):
    • Full Fine-tuning: ~0.5 it/s
    • LoRA (r=16): ~2-3 it/s
    • LoRA (r=8): ~3-4 it/s
    • Speedup: 4-6x faster with LoRA

  Hyperparameter Suggestions:
    • Learning Rate: 1e-4 to 5e-4 (higher than full fine-tuning)
    • LoRA Rank: Start with 8-16, increase if underfitting
    • LoRA Alpha: 2× rank (standard practice)
    • Dropout: 0.05-0.1 (prevents overfitting)
    • Batch Size: 1-2 (due to VAE memory)
    • Gradient Accumulation: 4-8 steps

  Convergence Tips:
    • Monitor action prediction accuracy separately
    • Use separate learning rates for action vs visual modules
    • Freeze early layers if dataset is small
    • Apply LoRA to action modules last for stability
